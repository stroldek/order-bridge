Order Bridge

Stage 2 · GOST source connector · v0.2.2

Розширення працює у popup-вікні Chrome. Ця сторінка — лише стартова інструкція.

Завантажити вихідний ZIP GitHub
  1. Розпакуйте ZIP у папку.
  2. Відкрийте chrome://extensions та ввімкніть Developer mode.
  3. Натисніть Load unpacked і виберіть розпаковану папку.
  4. Відкрийте GOST та авторизуйтеся у звичайному порядку.
  5. Натисніть значок Order Bridge, виберіть «Підключити», відкрийте «Замовлення» та оновіть сторінку.

Початкова історія буде позначена як історична. Нові замовлення перевірятимуться кожні 120 секунд. На Stage 2 передавання до CRM не виконується.
